# 入门

Tiger Studio 是一个学生兴趣社团。本网站是前门：产品、想法板、文档和支持。

## 你可以做什么

1. 浏览 [产品](/products)，查看公开仓库与工具。
2. [加入](/docs/getting-started/join)，以便在 Proj.Help 上发想法或回复。
3. 在交付或写指南时阅读这些文档：[Git](/docs/git)、[GitHub CLI](/docs/github-cli)、[Godot](/docs/godot)、[TypeScript](/docs/typescript) 以及 [网站](/docs/website)。
4. 只有需要帮助时才用 [支持](/support)，学某样东西怎么工作则不必。

## 两个 GitHub 仓库

- [`docs`](https://github.com/Tiger-Studio-WAB/docs) — 变成本手册的 Markdown 文件夹
- [`support`](https://github.com/Tiger-Studio-WAB/support) — 支持页的议题模板与帮助文案

在 `docs` 里加一个文件夹即可加一个分区。参见 [如何排版文档](/docs/how-to-format)。
