# Erste Schritte

<!-- Deutscher Entwurf zur Prüfung durch Mingli29 -->

Tiger Studio ist ein studentischer Passion-Club. Diese Website ist die Eingangstür: Produkte, ein Ideenboard, Docs und Support.

## Was du tun kannst

1. Unter [Produkte](/products) öffentliche Repositories und Tools ansehen.
2. [Beitreten](/docs/getting-started/join), um eine Idee zu posten oder auf Proj.Help zu antworten.
3. Diese Docs lesen, wenn du auslieferst oder Leitfäden schreibst: [Git](/docs/git), [GitHub CLI](/docs/github-cli), [Godot](/docs/godot), [TypeScript](/docs/typescript) und [die Website](/docs/website).
4. [Support](/support) nur nutzen, wenn du Hilfe brauchst — nicht, wenn du lernst, wie etwas funktioniert.

## Die zwei GitHub-Repos

- [`docs`](https://github.com/Tiger-Studio-WAB/docs) — Markdown-Ordner, die dieses Handbuch werden
- [`support`](https://github.com/Tiger-Studio-WAB/support) — Issue-Vorlagen und Hilfetexte für die Support-Seite

Lege in `docs` einen Ordner an, um einen Abschnitt hinzuzufügen. Siehe [Docs formatieren](/docs/how-to-format).
