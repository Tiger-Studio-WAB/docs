# 加入想法板

Proj.Help 就在本站的 [加入](/join) 下。

## 登录

使用 **GitHub** 或 **Microsoft**。GitHub 这条路不需要学校管理员审批。

登录后你可以：

- 发布一个希望别人帮忙的想法
- 如果你能帮忙就回复
- 在英文与中文界面之间切换

## 如果登录没有完成

那是支持问题，不是文档问题。打开 [支持](/support) 并提交议题。
