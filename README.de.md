# Tiger Studio Docs

<!-- Deutscher Entwurf zur Prüfung durch Mingli29 -->

Diese Seiten sind das Studio-Handbuch. Das Layout folgt derselben Idee wie Meta for Developers und die Microsoft-Fabric-Docs: links eine Abschnittsliste, eine Seite pro Markdown-Datei, Ordner als Themen.

## So ist diese Site aufgebaut

| Im Docs-Repo | Auf der Website |
| --- | --- |
| Ein Ordner | Ein Seitenleisten-Abschnitt |
| `index.md` oder `README.md` in diesem Ordner | Die Landingpage des Abschnitts |
| Jede andere `.md`-Datei | Eine Seite in diesem Abschnitt |
| `_category.json` | Optionales Abschnittslabel und Reihenfolge |

Ordner anlegen, Markdown hinzufügen — die Seite erscheint. Siehe [Docs formatieren](/docs/how-to-format).
