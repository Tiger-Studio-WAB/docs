# Git

Git tracks changes to files. Every studio repository — the [website](https://github.com/Tiger-Studio-WAB/Tiger-Studio-Website), [this handbook](https://github.com/Tiger-Studio-WAB/docs), [support](https://github.com/Tiger-Studio-WAB/support), and [WAB-Project-1](https://github.com/Tiger-Studio-WAB/WAB-Project-1) — lives in Git on GitHub.

You do not need Git to *read* these pages. You need it to clone a project, save work, and open a pull request.

## What Git does

| Job | Git command (later pages) |
| --- | --- |
| Copy a repo to your computer | `git clone` |
| See what changed | `git status` |
| Save a snapshot | `git commit` |
| Send it to GitHub | `git push` |
| Work on a feature without touching `main` | `git checkout -b` |
