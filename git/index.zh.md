# Git

Git 跟踪文件变更。每个工作室仓库——[网站](https://github.com/Tiger-Studio-WAB/Tiger-Studio-Website)、[本手册](https://github.com/Tiger-Studio-WAB/docs)、[支持](https://github.com/Tiger-Studio-WAB/support) 以及 [WAB-Project-1](https://github.com/Tiger-Studio-WAB/WAB-Project-1)——都在 GitHub 上的 Git 里。

阅读这些页面不需要 Git。克隆项目、保存工作、打开拉取请求才需要。

## Git 做什么

| 工作 | Git 命令（后续页面） |
| --- | --- |
| 把仓库复制到你的电脑 | `git clone` |
| 查看改了什么 | `git status` |
| 保存一份快照 | `git commit` |
| 发送到 GitHub | `git push` |
| 在不影响 `main` 的情况下做功能 | `git checkout -b` |
