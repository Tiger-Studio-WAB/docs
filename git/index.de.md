# Git

<!-- Deutscher Entwurf zur Prüfung durch Mingli29 -->

Git verfolgt Änderungen an Dateien. Jedes Studio-Repository — die [Website](https://github.com/Tiger-Studio-WAB/Tiger-Studio-Website), [dieses Handbuch](https://github.com/Tiger-Studio-WAB/docs), [Support](https://github.com/Tiger-Studio-WAB/support) und [WAB-Project-1](https://github.com/Tiger-Studio-WAB/WAB-Project-1) — liegt in Git auf GitHub.

Du brauchst Git nicht, um diese Seiten zu *lesen*. Du brauchst es, um ein Projekt zu klonen, Arbeit zu speichern und einen Pull Request zu öffnen.

## Was Git tut

| Aufgabe | Git-Befehl (spätere Seiten) |
| --- | --- |
| Ein Repo auf den Rechner kopieren | `git clone` |
| Sehen, was sich geändert hat | `git status` |
| Einen Snapshot speichern | `git commit` |
| Ihn zu GitHub senden | `git push` |
| An einem Feature arbeiten, ohne `main` anzufassen | `git checkout -b` |
