# Produkte

<!-- Deutscher Entwurf zur Prüfung durch Mingli29 -->

Öffentliche Arbeit steht unter [Produkte](/products). Jede Karte ist entweder eine Studio-Seite oder ein GitHub-Repository.

## Auf diesem Hub

- **Proj.Help** — Ideen und Antworten, unter [Join](/join)
- **Docs** — dieses Handbuch, aus dem `docs`-Repository
- **Support** — Hilfe und Issues, unter [Support](/support)

## Auf GitHub

Repositories in der [Tiger-Studio-Organisation](https://github.com/Tiger-Studio-WAB) erscheinen auf Produkte, sobald sie angelegt sind. Setze eine Homepage am Repo, wenn das Projekt eine Live-Site hat.

## Hier eine Produktseite hinzufügen

Lege `products/your-product.md` im Docs-Repo an. Folge [Docs formatieren](/docs/how-to-format).
