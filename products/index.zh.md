# 产品

公开工作列在 [产品](/products)。每张卡片要么是工作室页面，要么是 GitHub 仓库。

## 本枢纽上

- **Proj.Help** — 想法与回复，在 [加入](/join)
- **文档** — 本手册，来自 `docs` 仓库
- **支持** — 帮助与议题，在 [支持](/support)

## 在 GitHub 上

[Tiger Studio 组织](https://github.com/Tiger-Studio-WAB) 里的仓库一经创建就会出现在产品页。如果项目有线上站点，请在仓库上设置主页。

## 在这里加一个产品页

在 docs 仓库中创建 `products/your-product.md`。遵循 [如何排版文档](/docs/how-to-format)。
