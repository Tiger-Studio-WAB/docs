# Godot

<!-- Deutscher Entwurf zur Prüfung durch Mingli29 -->

Godot ist die Game-Engine, die das Studio für 2D-Arbeit nutzt. Das erste öffentliche Spiel-Repo ist [`WAB-Project-1`](https://github.com/Tiger-Studio-WAB/WAB-Project-1): eine Godot-**4.7**-2D-Plattformer-Vorlage (GDScript, nicht C#).

Du bearbeitest Szenen und Skripte im Godot-Editor. Git speichert das Projekt weiterhin. Committe den Editor-Cache nicht.

## Seiten in diesem Abschnitt

1. [Godot installieren](/docs/godot/install)
2. [Ein Projekt öffnen und ausführen](/docs/godot/open)
3. [Szenen, Skripte und Git](/docs/godot/scenes)

## Studio-Konventionen (kurz)

- Engine-Version: **4.7+** (Vorlage getestet auf 4.7.2)
- Sprache: **GDScript**, Standard-Editor (nicht .NET)
- Renderer: **GL Compatibility** für diese Vorlage
- `.uid`-Dateien: committen
- `.godot/`: niemals committen

Vollständiges Layout, Physik-Layer und PR-Regeln stehen in diesem Repo: `docs/GETTING_STARTED.md`, `docs/ARCHITECTURE.md` und `CONTRIBUTING.md`.
