# Godot

Godot 是工作室用于 2D 工作的游戏引擎。第一个公开游戏仓库是 [`WAB-Project-1`](https://github.com/Tiger-Studio-WAB/WAB-Project-1)：一个 Godot **4.7** 的 2D 平台跳跃模板（GDScript，不是 C#）。

你在 Godot 编辑器里编辑场景和脚本。Git 仍然保存项目。不要提交编辑器缓存。

## 本分区页面

1. [安装 Godot](/docs/godot/install)
2. [打开并运行项目](/docs/godot/open)
3. [场景、脚本与 Git](/docs/godot/scenes)

## 工作室约定（简短）

- 引擎版本：**4.7+**（模板在 4.7.2 上测试）
- 语言：**GDScript**，Standard（非 .NET）编辑器
- 渲染器：本模板用 **GL Compatibility**
- `.uid` 文件：要提交
- `.godot/`：永远不要提交

完整布局、物理层和 PR 规则在该仓库：`docs/GETTING_STARTED.md`、`docs/ARCHITECTURE.md` 和 `CONTRIBUTING.md`。
