# Tiger Studio 文档

这些页面是工作室手册。版式参考 Meta for Developers 和 Microsoft Fabric 文档：左侧是分区列表，每个 Markdown 文件一页，文件夹即主题。

## 本站如何构成

| 文档仓库里 | 网站上 |
| --- | --- |
| 一个文件夹 | 侧栏中的一个分区 |
| 该文件夹中的 `index.md` 或 `README.md` | 分区落地页 |
| 其他 `.md` 文件 | 该分区中的一页 |
| `_category.json` | 可选的分区标签与排序 |

加一个文件夹、写好 Markdown，页面就会出现。参见 [如何排版文档](/docs/how-to-format)。
